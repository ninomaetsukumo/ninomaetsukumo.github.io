## 重要事項

本レポートは公開情報のみを用いた独立OSINT事例研究です。刑事、民事、選挙法、税務、規制、倫理上の責任を認定するものではありません。政治献金、住所の共有、後援会での役職、友人関係、政府契約、公的事業への参加、企業関係、訂正、返金、修正、告発・告訴の存在だけで、不正行為が立証されるわけではありません。

## 結論先出し

JP-02では、高市早苗氏に関連する政治団体を中心に、**複数クラスター型の政治資金ネットワーク**が確認されました。最も強い証拠は公的記録です。政治資金収支報告書は寄附、資金移動、役職者、住所を示し、公式資料・企業資料・国会会議録は一部の事業関係、公的支援、後日の説明や追及を確認します。

一方で、本件を「一つの統一された寄附者ネットワーク」として扱うだけの証拠は確認されませんでした。複数のクラスターは同じ政治的受領者に収束しますが、寄附者同士の直接的な橋渡しが確認できないものも多くあります。

主要クラスター:

- **鳥羽博道 / 鳥羽珈琲** — 2024年の大口寄附と、藤川晋之助氏を通じた総裁選支援。
- **川井徳子 / 神奈我良 / ノブレス** — 長期の人的関係と、うぶすなの郷TOMIMOTOを含む事業・地域政策上の接点。
- **菊池攻 / 奈良トヨタ / 後援会インフラ** — 長年の関係と、木下剛志氏を介する正式な後援会構造。
- **中山雅照4社クラスター** — 同一代表者、同一住所、同一日、各250万円の寄附。
- **その他の企業クラスター** — 上武建設2件、天理技研等。
- **政治後援組織インフラ** — 奈良早志会、奈良県医師連盟、安藤紀明氏周辺の後援活動、後日の訂正。
- **新時代政策研究会 / 創高会 / 亀岡宏和 / Veanas / PoliLab関連** — 実在する役職・住所・取引先関係は確認される一方、不適切な資金循環は立証されていません。

## 証拠分類

| 区分 | 意味 |
|---|---|
| Verified Fact | 強い一次資料に直接裏付けられた事実 |
| Corroborated | 複数の信頼できる資料で裏付けられた事項 |
| Reported Information | 報道されているが一次資料で独立確認できていない事項 |
| Analytical Judgment | 確認済み事実に基づく分析 |
| Hypothesis | 未立証の説明仮説 |
| Negative Finding | 定義した公開情報調査で提案された関係を確認できなかったこと |
| Unknown / Unresolved | 現時点の証拠では判断不能 |

**基本原則:** source ≠ claim ≠ fact ≠ conclusion.

## 1. 中心政治団体

2024年の**自由民主党奈良県第二選挙区支部**の政治資金収支報告書は、高市早苗氏を代表者として記載し、本件の主要な寄附記録となっています。[SRC-0001]

奈良県の公開索引では後日の訂正履歴が確認されるため、現在オンラインで閲覧できる版をそのまま最初の公開版と扱うことはできません。[SRC-0002]

## 2. 主要寄附クラスター

### 鳥羽博道 / 鳥羽珈琲

2024年報告書は、鳥羽博道氏による個人寄附2件、合計1,900万円と、鳥羽珈琲による法人寄附を記録しています。[SRC-0001]

2025年12月9日の衆議院予算委員会で、高市氏は、資本金区分上の年間上限が750万円である企業から1,000万円の寄附を受け、判明後に250万円を返金したと答弁しました。[SRC-0003]

鳥羽氏自身の公開発言では、2024年の自民党総裁選で高市氏を支援し、選挙プランナー藤川晋之助氏に高市陣営への支援を依頼したことも確認できます。[SRC-0010]

### 川井徳子 / 神奈我良

同じ2024年支部報告書には、川井徳子氏個人1,000万円と、宗教法人神奈我良3,000万円の寄附が記録されています。神奈我良の代表者欄には川井氏の氏名が記載されています。[SRC-0001]

川井氏と高市氏の関係は2024年より前に遡り、2017年には高市氏、安堵町長、川井氏が、うぶすなの郷TOMIMOTOと地域活性化をめぐる公開企画で同席しています。[SRC-0008]

### 菊池攻 / 奈良トヨタ / 後援会

高市早苗連合後援会の2024年収支報告書は、

- 代表者: **菊池攻**
- 会計責任者・事務担当: **木下剛志**
- 所在地: **大和郡山市筒井町940-1**

と記載しています。[SRC-0005]

自動車業界の公開資料では、菊池氏と高市氏は30年以上の関係があるとされ、菊池氏が長年後援会を率いてきたことが記録されています。[SRC-0011]

このため、企業寄附クラスターと高市氏の後援会・事務所インフラを結ぶ実在の組織的接点が確認できます。ただし、それ自体は不当な影響力を意味しません。

### 中山雅照 4社クラスター

2024年支部報告書は、2024年8月23日に次の4件を記録しています。

- 三幸（株） — 250万円
- 大統（株） — 250万円
- 生奈興産（株） — 250万円
- 巳斗（株） — 250万円

4件すべてで代表者は**中山雅照**、住所も同一です。合計は**1,000万円**です。[SRC-0001]

これは公式記録上の内部クラスターです。同一日・同額という事実だけから、違法な分割寄附や規制回避とは評価しません。

また、このクラスターから鳥羽、川井、菊池、安藤、木下、亀岡、Veanas、創高会、新時代政策研究会への有意な橋渡しは確認されませんでした。

### 上武建設

2024年支部報告書は、2024年8月23日に上武建設名義の2件を記録しています。

- 50万円 — 上武尚宏
- 150万円 — 上武建一

住所も別記載です。[SRC-0001]

奈良県資料は、上武建設株式会社が上武建一氏を代表者とする建設会社であることを確認します。[SRC-0009]

### 天理技研

現在の公式支部報告書は、**天理技研（株）から200万円、2024年9月19日**の寄附を記録し、代表者欄には手塚明宏氏が記載されています。[SRC-0001]

奈良県の入札参加資格資料では、天理技研が建設コンサルタント・測量関連分野の事業者として確認できます。[SRC-0012]

後に、政府契約中の企業による寄附に関する選挙法上の問題を主張する告発・告訴報道がありましたが、これは主張であり、違反認定、起訴、有罪判決を意味しません。[SRC-0013]

## 3. 寄附者間の接続テスト

繰り返し行った公開情報調査では、次の主要関係は確認されませんでした。

- 鳥羽 ↔ 川井 / 神奈我良
- 鳥羽 ↔ 菊池 / 奈良トヨタ
- 鳥羽 ↔ 天理技研
- 菊池 / 奈良トヨタ ↔ 川井 / ノブレス
- 菊池 / 奈良トヨタ ↔ 天理技研
- 中山クラスター ↔ 鳥羽 / 川井 / 菊池 / 安藤 / 木下 / 亀岡
- 上武建設 ↔ 川井 / ノブレス
- 天理技研 ↔ Branch B/C/D

これは「私的関係が存在しない」ことの証明ではなく、定義した公開情報調査で関係を確認できなかったという**ネガティブ・ファインディング**です。

## 4. 政治後援組織ブランチ

2023年の奈良早志会収支報告書には、2023年4月12日に奈良県医師連盟から100万円、4月28日に奈良早志会から高市氏後援団体へ100万円の移動が記録されています。さらに他の送金を含めると、報告上の年間合計は202.8万円です。[SRC-0006; SRC-0007]

これらは取引を確認するものであり、同一資金の単純な通過、隠蔽目的、違法な協調までは示しません。

奈良県医師会と奈良県医師連盟は別組織として扱います。

## 5. 川井 / ノブレス / うぶすなの郷 公的部門ブランチ

公的資料等により、FY2015の総務省「ローカル10,000プロジェクト」利用と、その後の宿泊・飲食・文化体験施設としての運営が確認されています。[SRC-0008]

安堵町資料では、旧富本憲吉記念館への過去の公的支援、後の駐車場用地利用、計画策定等との関係、開業後も町全体の事業・雇用創出が政策課題として残っていたことが確認できます。[SRC-0008]

しかし、高市氏が個人的に事業を選定した、専門審査を操作した、2024年寄附が過去の公的支援の対価だった、という証拠は確認されませんでした。

当初申請書、正確な補助金・融資構成、比較可能なKPI系列は未回収です。これは**評価可能性の空白**であり、隠蔽の証拠ではありません。

## 6. 創高会 / 亀岡 / Veanas

創高会の2024年収支報告書は、梶井光氏を代表者、亀岡宏和氏を会計責任者・事務担当として記載し、自由民主党奈良県第二選挙区支部から20万円（2024年9月10日）の寄附を記録しています。[SRC-0004]

企業情報集約サイトは亀岡氏をVeanas合同会社の代表社員として扱い、同社所在地を筒井町940-1としています。ただし直接の商業登記簿は未保存です。

確認できる経路は、

`高市氏支部 → 創高会 → 亀岡 → Veanas`

です。これは人的・組織的近接性を示しますが、不適切な支配を示すものではありません。

## 7. 新時代政策研究会 / 木下 / PoliLab

高市早苗連合後援会の報告書は、木下剛志氏を筒井町940-1における会計・事務担当として位置づけています。[SRC-0005]

二次報道では、Veanasがグッズ販売・発送等でPoliLab合同会社を利用し、新時代政策研究会が2024年にPoliLab名義の事業者へ約3,330万円を広告関連費として支出したとされています。[SRC-0014]

ただし、JP-02はPoliLabの正確な法人同定と一次報告書上の支出行をまだ独立確認していません。そのため、循環資金、私的利益供与、自己取引は未立証です。

## 8. 外部政治・宗教コンテキスト

参政党を含む外部政治・宗教的な関係候補も検証しました。

しかし、JP-02の主要寄附者クラスターから、外部主体へつながる十分な資金・役職・正式組織上の橋渡しは確認されませんでした。このため、公開版の中心的所見には含めません。

## 9. ネガティブ・ファインディング

- 主要2024年寄附者すべてをつなぐ単一ネットワーク

## 最終分析

JP-02は、政治献金、後援組織、企業グループ、専門職政治団体、公的部門との接点から成る複数のクラスターを確認しました。

一部の接続は強く確認できます。一方で、他の寄附者クラスターは内部では明確でも、外部への橋渡しは公開記録から確認できません。

したがって、本件で確認できるのは**複数クラスター型のネットワーク**であり、全関係者が一つの協調構造として行動したとの結論ではありません。
